# WK1-PM1-CYBERSECURITY-LAB-SETUP

## 1. Project Overview
This project is about setting up a personal cybersecurity lab for ethical hacking and security testing.

## 2. Objective
To create a safe and isolated environment to practice cybersecurity skills without affecting the main system.

## 3. Purpose of the Lab
The purpose is to learn penetration testing, network scanning, and vulnerability assessment.

## 4. Lab Architecture
Host OS: Windows 11 -> Hypervisor: VirtualBox -> Guest OS: Kali Linux

## 5. Lab Configuration
- VirtualBox 7.0
- Kali Linux 2024.2
- RAM: 4GB Allocated, Storage: 50GB

## 6. Lab Setup Procedure
1. Downloaded and installed VirtualBox
2. Downloaded Kali Linux ISO
3. Created a new VM in VirtualBox
4. Installed Kali Linux
5. Tested basic commands

## 7. Problems Encountered and Solutions
Problem: Kali was very slow. 
Solution: Increased RAM from 2GB to 4GB and enabled Virtualization in BIOS.
